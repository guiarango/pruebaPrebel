# Prueba técnica — React Hooks

## 1. Clonar el repositorio

```bash
git clone <URL_DEL_REPOSITORIO>
cd <NOMBRE_DEL_REPOSITORIO>
```

## 2. Instalar dependencias y correr el proyecto

```bash
npm install
npm run dev
```

Abre [http://localhost:5173](http://localhost:5173) en tu navegador.

## 3. Dónde encontrar las preguntas

Las preguntas están en `src/exam/`:

| Archivo | Pregunta |
|---------|----------|
| `src/exam/Pregunta1.tsx` | Cronómetro — `useState` + `useRef` |
| `src/exam/Pregunta2.tsx` | Conversor de temperatura — `useMemo` + `useEffect` |

Cada archivo tiene comentarios `// TODO` que indican exactamente qué debes implementar, no los borres.

## 4. Entregar la prueba

1. Crea una rama con tu nombre:
   ```bash
   git checkout -b nombre-apellido
   ```
2. Haz commits con tus cambios.
3. Sube la rama y abre un Pull Request al repositorio principal.
